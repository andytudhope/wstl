The original Status heart variant is preserved in `status-heart.svg`.

Source: [Status brand kit](https://status.app/brand), downloaded 30 October 2026:
[variant-assets.zip](https://res.cloudinary.com/dhgck7ebz/raw/upload/Brand/variant-assets.zip),
`Variants/Mark/Mark_01_SVG.svg`.

`src/StatusLoversArt.sol` uses the exact white heart path. The background is new
generative artwork. Its gradient and blur endpoints use only the main and custom
colours listed on the brand page:

- Main: Dark `#09101c`, White `#ffffff`, Blue `#2a4af5`.
- Custom: Purple `#7140fd`, Orange `#ff7d46`, Army `#216266`, Turquoise `#2a799b`,
  Sky `#1992d7`, Yellow `#f6b03c`, Pink `#f66f8f`, Copper `#cb6256`,
  Camel `#c78f67`, Magenta `#ec266c`.

The token ID seeds colour selection, gradient direction, and the position, size,
and blur of the colour fields. The centred heart stays the same on all 50 tokens.
